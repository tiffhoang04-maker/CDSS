# Clinical Workflow

## 1. Initial Assessment
- Determine whether an immediate life threat is present.
- Request missing airway, breathing, circulation, neurologic, and exposure data.
- Obtain available vital signs.
- Do not proceed to a final diagnosis when critical information is missing.

## 2. Differential Diagnosis
- Consider all reported symptoms and findings.
- Do not eliminate a diagnosis without stating the contradicting evidence.
- Rank diagnoses by supporting and contradicting evidence.

## 3. Diagnostic Refinement
- Recommend the next question, examination, or test that would best
  distinguish among leading diagnoses.
- Account for unavailable mission resources.

## 4. Diagnosis
- Select a final diagnosis only when evidence is adequate.
- Report remaining uncertainty.

## 5. Treatment and Monitoring
- Recommend stage-appropriate care.
- Cite knowledge-graph context when available.
- Create a resource-gap statement when required capabilities are unavailable.

## 6. Reassessment
- Update patient state after every observation or intervention.
- Return to assessment when the patient changes or uncertainty remains.
